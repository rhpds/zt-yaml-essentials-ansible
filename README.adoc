= YAML Essentials for Ansible

A hands-on lab teaching YAML fundamentals through practical Ansible examples.

== Lab Overview

This interactive workshop teaches developers, SREs, and platform engineers the fundamentals of YAML syntax and structure through building real Ansible inventories and playbooks.

*Duration:* 40 minutes +
*Experience Level:* Beginner +
*Prerequisites:* None - no prior YAML or Ansible knowledge required

=== Learning Objectives

By the end of this lab, you will be able to:

* Master YAML syntax: scalars, lists, dictionaries, and booleans
* Create properly structured Ansible playbooks and inventories
* Use variables and loops to make playbooks flexible
* Write effective comments for documentation
* Debug common YAML errors using `yamllint` and Ansible tools

== Lab Modules

=== Module 1: YAML Fundamentals (10 min)

Learn basic YAML data types and create your first inventory file.

* Scalars, lists, and dictionaries
* Indentation rules (2 spaces, no tabs)
* Case sensitivity
* Create `inventory.yml` with host groups and variables

=== Module 2: Your First Playbook (10 min)

Write a working Ansible playbook with multiple tasks.

* Playbook structure (`---`, `name`, `hosts`, `tasks`)
* Execute tasks (ping, install packages, manage services)
* Module parameters and FQCN (Fully Qualified Collection Names)
* Boolean values (`become: true`)

=== Module 3: Variables & Best Practices (10 min)

Make playbooks flexible with variables and proper documentation.

* Define variables in the `vars:` section
* Use Jinja2 syntax: `"{{ variable_name }}"`
* Loop over list variables
* Add comments for documentation
* Apply YAML best practices

=== Module 4: Debugging YAML (10 min)

Identify and fix common YAML errors.

* Fix indentation problems
* Catch tabs vs spaces issues
* Debug case sensitivity errors
* Handle quote requirements
* Use `yamllint` and `ansible-playbook --syntax-check`

== What You'll Build

Throughout the lab, you'll create:

* `inventory.yml` - A structured inventory with webserver and database groups
* `site.yml` - A documented playbook that installs and configures Apache
* Multiple example files demonstrating common errors and their fixes

[NOTE]
====
The lab uses example hostnames (web1.example.com, web2.example.com, db1.example.com) that resolve to localhost, allowing you to test your YAML syntax with real Ansible execution.
====

== Business Scenario

*TechStart Inc.* is a growing technology company modernizing their infrastructure. Their operations team needs to automate the deployment of web servers across their RHEL fleet using Ansible. Before writing complex automation, the team must first master YAML - the foundation of all Ansible content.

This lab provides the essential YAML skills needed to write clear, maintainable Ansible playbooks.

== Key Takeaways

After completing this lab, learners will understand:

* ✅ YAML syntax rules: indentation, case sensitivity, data types
* ✅ How to structure Ansible inventories and playbooks
* ✅ Variable usage and Jinja2 templating basics
* ✅ YAML best practices for maintainability
* ✅ Debugging techniques for common YAML errors
